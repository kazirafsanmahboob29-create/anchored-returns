Using the analysis workspace

The fixed cohort contains 22 primary decisions and one supplemental settlement. Select a preset, filter the table and check individual orders to build a comparison. Each summary reports its denominator and missing values.

Choose a national series

RRA comparisons use exact rider-excluded half-years and require publication by the written order date. EEI comparisons are separately reconstructed electric base-rate means and are always retrospective. They provide additional historical context while preserving the limits of the strict RRA series.

Keep or export a selection

Save selection stores the current visible selection in this browser. Restore loads it again. Copy link preserves the selected order IDs, weighting and national series. Export selection CSV contains the selected records. Export analysis report contains the selection, recalculated summaries, source references and input fingerprints. Import a selection accepts a matching JSON report and recalculates its results from the current records. None of these actions changes the cohort or source records.

Compare weighting choices

One value per order weights each observed document equally. One value per proceeding first averages observed awards in each recorded proceeding group. Request gaps and national differences retain their own observed-pair denominators. Joint-service orders can contribute two national service comparisons.

Using the research workspace

I use this workspace to connect descriptive findings to original utility decisions and preserved public data.

Explore an observation

  1. Choose passages, numeric facts or source documents in the evidence explorer.
  2. Filter by state, evidence category, section or search term. Export the filtered records as CSV.
  3. Open the saved PDF link to inspect the original page. The reader checks the PDF's SHA-256 fingerprint and provides native page text, navigation, and the official source link.
  4. Use Trace a finding to inspect the observations, calculation and sensitivity checks behind a result.

Use market data

The market chart checks FRED DGS10 and the official Treasury XML feed when the page opens. Completed retrievals are preserved in hosted storage. A source check reuses a retrieval completed within the preceding 15 minutes; routine page loads reuse a retrieval for one hour. The latest observation date can differ between providers. Comparisons use matching dates from the current calendar year and retain discrepancies.

The chart, dated slider and CSV export use the displayed market retrieval. Download market retrieval supplies the observations, comparison records, timestamps and source fingerprints. Research figures and historical order-date matches remain attached to the fixed empirical release dated October 4, 2026. Live updates do not revise those findings.

Reproduce the research

Download research bundle contains the checked analysis tables in CSV and Stata format, R and Stata figure scripts, generated R and Python figures, and a release manifest. Research tool source code contains the Python pipeline, tests, methodological documents and preserved input records. Original PDFs are available in the online library and through the official source URLs.

The source tools run locally with Python and the packages listed in requirements-lock.txt. From the extracted source directory, run python -m src.research --help to list commands. R figures require R; Stata scripts require a licensed Stata installation. The release records which runtimes were actually executed.

Record a separate coding pass

The coding workspace contains 67 paragraphs and footnotes from three orders. Reference labels are omitted. A rater can download a draft, resume it, and export a completed rating file. Files are saved to the rater's device; no ratings are submitted to the site. A completed file is not independent reliability evidence until its provenance and independence are documented and it is compared with another eligible pass.

Current research limits

The 15-order allocation remains provisional. Five compatible half-year benchmarks are missing. Independent ratings have not been collected. These gaps remain explicit in the workspace. The existing results describe entered records and do not establish a causal anchoring effect.
