The evidence explorer provides the underlying passages, figures and original documents.</p><h2>Build a comparison</h2><p>Choose the primary cohort, include the supplemental settlement, or load the original pilot proposal. Filter by state, utility service and written-date period. Check individual orders to change the analysis selection. The summaries use only the currently visible, checked rows. Select visible and Clear visible operate on the current filter results.</p><p>One value per order weights each observed award equally. One value per proceeding averages observed awards within each recorded proceeding group before summarizing across groups. Missing awards do not become zero. Request differences and national comparisons keep their own observed-pair denominators.</p><p>RRA comparisons require the preceding exact half-year, the same service, rider exclusion and publication by the written decision date. EEI comparisons are a separate retrospective electric base-rate reconstruction. No gas or 2026 value is inferred from that workbook.</p><h2>Preserve work</h2><p>Save selection stores the current selection in the browser. Restore loads it again. Copy link preserves the order IDs, weighting and national series. Export selection CSV contains the selected records. Export analysis report adds the calculation summary, source references and input fingerprints. Import a selection accepts a matching JSON report and recalculates the results. These operations do not alter the cohort or original evidence.</p><h2>Inspect evidence and sources</h2><p>Search the passage, numeric-fact or source-library tab. Filters and pagination update the displayed records. Each record links to its original endpoint and preserved PDF page. Exact excerpts, printed units, event dates and SHA-256 fingerprints remain available for review.</p><p>Refresh Treasury sources retrieves the connected public FRED and Treasury feeds. A completed retrieval is preserved with its raw source files. Historical research findings keep their fixed input vintage.</p><h2>Run the local tools</h2><pre><code>./research serve
./research status
./research check
./research overview
./research analyze</code></pre><p>The local service prints its address. The hosted edition provides the same research records with a browser PDF reader and durable market retrievals. <a href="REPRODUCIBILITY.md" rel="noopener noreferrer">Reproduction instructions</a> describe environment setup, original-source restoration, R and Stata materials and verification limits.</p></main></body></html>
