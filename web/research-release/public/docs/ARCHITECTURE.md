Primary documents and dated external data form the evidence layer. Python modules validate and transform that evidence into a portable release. Browser and Worker modules provide the analysis interface and connected data service.</p><h2>Research modules</h2><p><code>research_ledger.py</code> checks source identity, exact page text and numeric roles. <code>research_sample.py</code> preserves the original quota design. <code>research_cohort.py</code> validates the expanded cohort against every eligible screening record, and <code>cohort_facts.py</code> validates additional numeric entries without rewriting the frozen first pass. Benchmark modules retain their own source definitions and calculation rules.</p><p><code>research_overview.py</code> assembles the validated payload. <code>research_insights.py</code> calculates descriptive comparisons. <code>research_analysis.py</code> exports CSV and Stata tables and runs available Python and R figures. Existing output directories are immutable releases; <code>reports/analysis/latest.json</code> points to the current one.</p><h2>Browser modules</h2><p><code>presentation/workspace/analysis.mjs</code> contains pure selection, conversion, summary, import-validation and CSV functions. It has no DOM or network dependency. <code>index.mjs</code> binds those functions to the interface. The evidence explorer remains in <code>presentation/app.js</code>.</p><p>Saved selections use browser storage and can be exported as JSON. They do not alter the cohort or source records. An imported selection must match the cohort fingerprint, contain known unique order IDs and use a recognized weighting. Results are recalculated from the current evidence rather than accepted from an imported report.</p><h2>Hosted service</h2><p>The prepared repository&#x27;s <code>web/worker/</code> contains the request router, official market-feed parsers and PDF-reader routes. The service retrieves FRED CSV and Treasury XML over HTTPS. It writes complete retrieval objects before advancing the saved-snapshot pointer. Failed retrievals retain the last complete snapshot. Historical findings are never overwritten by a market refresh.</p><p>The build exports static evidence records and a small Worker entry point. Original PDFs are allowlisted by saved path and SHA-256. The PDF reader renders the original file in the browser. Hosting configuration contains no credentials, and runtime credentials are not included in the repository.</p></main></body></html>
