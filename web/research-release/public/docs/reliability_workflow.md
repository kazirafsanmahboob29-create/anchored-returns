  --output reports/human-inter-rater-agreement.json</code></pre><p>The output file must be new; existing results are preserved. The importer rejects changed packet inputs, missing units, duplicate units, blanks, booleans, invalid code lists, missing blinding documentation, identical reported identities in a two-rater comparison and implausible timestamps. Rating activity must follow the packet freeze and precede import.</p><h2>Interpret the result</h2><p>The report calculates Cohen&#x27;s kappa separately for each code, alongside raw agreement, marginal counts and the four cells of the binary agreement table. The planned 0.70 target applies to MKT, PEER, OWN, GRAD and CONC. A code with no variation can have undefined kappa even when all ratings agree; it does not establish perfect reliability or satisfy the target.</p><p>A human-to-first-pass comparison and human inter-rater agreement are reported as different comparison types. Identity and blinding remain reported attestations. File checks cannot authenticate a person or independently prove that reference labels were concealed. Agreement from clustered paragraphs is also not evidence that three independent cases represent the entire sample.</p><p>No completed independent observation files exist in the current release.
