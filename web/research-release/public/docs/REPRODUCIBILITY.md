Reproduction requires the preserved inputs, the Python environment and Node.js for browser and Worker tests. R is optional. No API key is required for the public market feeds.</p><h2>Research environment</h2><pre><code>python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e &#x27;.[test]&#x27;
./research national
./research check
./research overview
./research analyze</code></pre><p>The <code>research</code> launcher uses an activated Python environment, a project <code>.venv</code>, or the original project environment. <code>requirements-lock.txt</code> records the original environment; <code>pyproject.toml</code> declares the smaller runtime dependency set.</p><p>Original PDFs are kept outside Git. The prepared project folder includes preserved originals for local use, and the separate source archive retains those files for transfer. Restore that archive at the repository root before a full evidence check. <code>scripts/fetch_sources.py</code> can alternatively retrieve documents from their recorded source URLs, accepting a file only when its SHA-256 matches the preserved record. If an endpoint now returns a different file, the check fails rather than silently replacing the historical source.</p><pre><code>python scripts/fetch_sources.py --check
python scripts/fetch_sources.py --download</code></pre><p>The original coding template and codebook are retained as methodological inputs. Personal project summaries and correspondence drafts are not needed to run the tools.</p><h2>Checks</h2><pre><code>python -m pytest -q
node --test tests/workspace/*.test.mjs tests/national/*.test.mjs</code></pre><p>The browser calculations have separate tests for precision, missing values, joint services, proceeding weights and imported selections. Research tests validate the evidence trail and cross-software exports. Synthetic values used by tests are confined to test fixtures and are not empirical observations.</p><h2>Hosted web service</h2><p>In the prepared repository:</p><pre><code>cd web
node scripts/build.mjs
node --test tests/*.test.mjs
node scripts/validate-release.mjs
node scripts/preview.mjs</code></pre><p>The preview prints its local URL. <code>web/research-release</code> is a portable export of the checked research state. The original working folders can recreate that export with <code>python -m scripts.build_hosted_release ../anchored-returns-site/research-release</code>.</p><p>R figures use base graphics. Native Stata code and Unicode DTA exports are included; native Stata execution has not been verified. The evidence manifest records which programs actually ran. Reproduction never creates independent human coding ratings.</p><p>The national-study download is self-contained for its own calculations. It includes the preserved EEI workbook, Treasury input files, Python modules and native statistical scripts. It does not require the New England original-order PDFs. See <a href="national_study.md" rel="noopener noreferrer">national_study.md</a> for the exact exclusions, comparison windows and grouping rules.</p></main></body></html>
