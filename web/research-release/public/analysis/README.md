Every run creates a new directory under <code>reports/analysis/</code>. An installed R runtime can be selected with <code>--rscript /path/to/Rscript</code>. <code>--skip-r</code> produces Python outputs and datasets while recording that R was not executed. <code>--output /path/to/new-directory</code> creates a separate release without changing the current site or pointer. Existing release directories are preserved.</p><h2>Run Stata</h2><p>No Stata installation was located on the research computer. It does not verify native Stata execution.</p><p>In a licensed Stata session, replace the two directory placeholders with the release&#x27;s <code>data</code> folder and a new output folder:</p><pre><code>do &quot;analysis/figures.do&quot; &quot;RELEASE_DIRECTORY/data&quot; &quot;NEW_STATA_OUTPUT_DIRECTORY&quot;</code></pre><p>The do-file checks request-award arithmetic and coding denominators, then exports three PDF/PNG graphs and <code>checks.csv</code>. Compare that file with the release&#x27;s <code>r/checks.csv</code> before reporting a three-software calculation check. Native Stata output is not included in the current manifest and must not be described as executed until the run has actually succeeded.</p><h2>Tables and measurement choices</h2><div class="doc-table"><table><thead><tr><th>Table</th><th>Observation and meaning</th></tr></thead><tbody><tr><td><code>outcomes</code></td><td>One entered decision. <code>request_pct</code> and <code>award_pct</code> are percentage points, such as 9.50. <code>gap_bp</code> is <code>(award_pct - request_pct) * 100</code>. ./research verify-treasury</code></pre><p>The Treasury comparison downloads the official <a href="https://home.treasury.gov/treasury-daily-interest-rate-xml-feed" rel="noopener noreferrer">XML feed</a> for the years needed by the matched decisions. Raw XML, parsed values and retrieval dates are preserved separately from FRED. The current comparison checks 1,440 overlapping dates and all nine decision-date observations, with no disagreements. It is a comparison of dissemination paths for nominal ten-year Treasury yields, not an independent measurement of coding reliability. After refreshing FRED, rerun <code>verify-treasury</code> before generating a new analysis release.</p><p>The source audit permits reviewed commission, publisher, university, issuer and government endpoints, checks every saved fingerprint and runs the existing evidence validators. It excludes the synthetic software demonstrations from empirical tables. This establishes traceability and calculation integrity; interpretation, final eligibility and independent coding agreement remain separate research questions.</p><p>The feeds currently end on different dates: FRED reports 5.24% for October 1, while Treasury reports 5.28% for October 2. The later Treasury value is preserved as separate source evidence; it is not inserted into DGS10. Only same-date overlap contributes to the 1,440-date comparison.</p><h2>Reading the figures</h2><p>R generates a request-award comparison, case-specific coding shares and verified national comparison points. Python generates the exact benchmark coverage matrix and the Treasury-context figure. Stata code implements the same three graph subjects as R. No line connects missing benchmark periods, and no regression or significance claim is calculated from this incomplete set of decisions.</p><p>The complete first passes have unequal lengths: nine Commission-analysis units for New Hampshire, three for Versant and 33 for Green Mountain Power. A longer section should not receive the interpretation of more independent decisions. The recorded codes remain assisted first-pass interpretations with independent agreement unmeasured.</p><p>The current export also includes <code>request_gap_sensitivity</code>, <code>reliance_weighting</code> and <code>benchmark_comparisons</code>, in both CSV and DTA form. The first table removes one entered request-award pair at a time and recomputes the median; it does not estimate a confidence interval. The second retains pooled and equal-order reliance shares with their denominators. The third compares an entered original award with an exact half-year benchmark only if the report was published by the written decision. Missing periods and later publications remain unfilled. Approved settlements retain their award kind and timing note. Publication before a written report does not establish availability when an earlier settlement was agreed. Contextual annual and enhanced-dataset reports appear in the source inventory but do not enter the benchmark table.</p><h2>Reconstructed H2 2019 benchmarks</h2><p>The release includes <code>benchmark_decisions.csv</code> and <code>.dta</code>: all 126 decisions from the original annual Table 5, including 47 rows without an ROE. The <code>limited_issue_rider</code> flag retains the publisher&#x27;s LIR classification. <code>included_h2</code> identifies numeric, non-rider rows from July through December. Electric and gas rows yield 19 and 23 included observations and means of 9.70% and 9.75%, rounded half up to two decimal places. The JSON evidence file also retains exact native-text spans and the unrounded result.</p><p>The parser verifies the original report&#x27;s publication date, data-compilation date and rider definition, and reconciles four annual count/mean controls before any half-year mean is accepted. A missing row, changed ROE or changed rider flag fails validation. Rounded annual and first-half means are never subtracted to derive H2. R, Python and prepared Stata figure notes identify the reconstructed period.</p></main></body></html>
