# Source rights and attribution

The research records identify the originating commissions, publishers and public data providers. Availability from a public URL does not transfer ownership of the underlying document or dataset. Original source notices remain intact. No additional license is asserted for third-party material.

The source code and original research documents identify Kazi Rafsan Mahboob as the project author. No blanket redistribution license is applied to the complete evidence archive. Source files are separated from the Git upload package so that the repository, software and original documents retain distinct attribution and distribution histories.

The hosted PDF reader uses PDF.js under its existing Apache 2.0 license. Its license, notices, version and acquisition provenance remain in the vendor directory.
