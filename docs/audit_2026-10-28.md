## Fixes made during the audit

The full evidence command previously called an early development audit that required a ZIP outside the repository. It then passed portable document paths to a manifest reader that required absolute paths. A normal restored clone could therefore pass calculation tests while failing `research check --full`.

The current full check resolves empirical files from the repository root, verifies the PDF hashes and reproduces their page text. The original development audit remains available through `--legacy`, with its separate prerequisites stated explicitly. New regression tests cover other working directories, altered PDFs, altered extracted text, missing manifests and paths that escape the project root.

## Research status

The numerical results use the same 533 complete observations and 188 later-case predictions as the October 26 study. The extension adds paired uncertainty, annual comparisons, equal-group weighting and state influence checks. It is a post hoc evaluation of fixed predictions.

Independent passage-coding agreement is still unmeasured. Five strict historical benchmark periods remain unresolved. Native Stata execution is not verified. Restricted source endpoints are recorded as access restrictions, rather than treated as successful downloads. These limits remain visible in the project and are not filled with synthetic research records.
